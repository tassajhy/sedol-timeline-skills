# 세돌이들 타임라인 작성 skills

SOOP 다시보기의 자막·채팅·미션·방제 변경·AI 요약을 참고하여 이세계아이돌 팬 타임라인과 댓글 분할본을 작성하는 스킬입니다. 방송국별 하트·문체·용어 프로필을 지원합니다.

## 사용 방법

1. `SKILL.md`를 내려받아 사용 중인 AI 도구가 지원하는 스킬 폴더에 `soop-vod-timeline/SKILL.md` 형태로 넣어 주세요.
2. AI 도구에 SOOP 다시보기 주소를 주고 타임라인 작성을 요청해 주세요.
3. 게시 전에 생성된 타임라인의 화자·시간·개인정보를 확인해 주세요. 댓글 게시에는 별도의 사용자 승인이 필요합니다.

수집에는 Node.js 20 이상의 표준 기능이 필요합니다. 브라우저 화면 확인에는 스킬에 설명된 Playwright 호환 기능이 필요하며, 실제 지원 여부는 사용하시는 AI 도구에 따라 달라집니다.

## 포함한 기능

- 여러 영상 파트의 누적 시간, 자동 자막과 채팅·미션·방제 변경·AI 힌트를 정리합니다.
- 방송국 프로필과 이세계아이돌 멤버별 하트 표기를 적용합니다.
- 시간당 약 25줄의 요약판과 덩어리당 3,700자 이하의 댓글 분할본을 작성합니다.
- 불확실한 장면은 필요한 영상 영역만 확인하도록 안내합니다.

## 개인정보와 보안

기본 수집은 쿠키를 보내지 않으며, 생성 데이터와 개인 프로필은 공개 저장소 밖에 저장합니다. 수집용 키·채팅 URL을 메타 파일에서 제외하고, 구간 입력에는 시청자 가명·일부 개인정보 가림·외부 데이터 경계를 적용합니다.

자동 가림은 완전한 익명화를 보장하지 않습니다. `stations/`, 수집 JSON, 구간 입력·초안, 캡처, 인증정보와 브라우저 세션을 공개 저장소에 올리지 말아 주세요. 자세한 실행 조건과 보안 경계는 [SKILL.md](SKILL.md)를 확인해 주세요.

## 확인한 범위

모의 수집·보안 회귀 검사와 비챤 채널의 공개 다시보기에서 기본 정보·자막·채팅·방제 이력의 샘플 응답 및 실제 영상 재생을 확인했습니다. 전체 방송의 타임라인 작성과 자동 캡처·로그인 연결의 모든 실제 경로를 검증한 것은 아닙니다.
